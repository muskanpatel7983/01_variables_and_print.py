### 📅 Day 2: what I learn next this./ Data Types & type() function

**Key Learnings:**
- **Data Types:**
  - `str` (String): Quotes ke andar ka text (e.g., `"Muskan"`, `"Agra"`)
  - `int` (Integer): Poora number bina decimal ka (e.g., `20`, `10`)
  - `float`: Decimal / dashamlaw wala number (e.g., `5.5`)
- **`type()` Function:** Variable ke andar kis type ka data hai, yeh pata karne ke liye (e.g., `type(naam)` gives `<class 'str'>`).
- **Calculations:** Variables ke sath math operations direct `print()` mein kar sakte hain (e.g., `age + 5`).
